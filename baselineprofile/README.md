# Historical benchmark journeys (excluded)

This module is deliberately not included by settings.gradle.kts. Its historical
journeys query Prism-era onboarding, lyrics and music controls that do not match
current Photon screens. It cannot provide performance evidence for Photon.
The target/package now point to the original :old-photon application rather than
the unrelated Firebase :app. Do not enable this module until journeys are rewritten
and exercised against current screens; no baseline profile is generated by it now.
Internal upstream names in the production module are intentional and are not its
application ID. No application rename or user-data migration is needed.

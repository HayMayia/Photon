# v1.0.0 Beta

- Photon now checks public Photon releases from Home and Settings on mobile and TV. Newer updates download inside the app; package, version and signing identity are checked before Android asks for installation approval. It includes beta releases and never offers Prism as a Photon update.
- The current 0.13 installation does not contain an updater. Install this version once over the existing application, without uninstalling. Subsequent compatible releases can be offered through Home. Android may require “Install unknown apps” permission for Photon; installation is never silent.
- TV playback pauses when returning to browsing or when Photon loses foreground activity and cannot be resumed from background media commands. TV picture-in-picture is disabled. Mobile background playback remains unchanged.
- Settings → Music Photon, "Prism" opens the official upstream direct APK download. Prism is a separate app by Yigder, not a renamed/integrated Photon component, and has its own license/data handling.
- Automatic TV interface, fullscreen/details Back flow, remote controls, shared speed/caption settings and other 0.13 features remain.

This is a beta, not a Google/YouTube verification, unrestricted-login guarantee or all-TV certification. Install only the official signed Photon.apk asset. Keep downloads/data by installing over the existing app with the same permanent signature. Native installer, updates and foreground-only TV behavior still need physical device checks.

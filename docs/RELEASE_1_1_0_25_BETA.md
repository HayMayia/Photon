# Photon 1.1.0.25 Beta

- Correct the detached navigation button: it is a user-assigned Google playlist shortcut, not Shorts. First tap opens a playlist chooser; selecting a playlist saves and opens it. Subsequent taps open that exact playlist. Long-press or Settings → Appearance → Playlist shortcut changes it; the chooser also offers Clear.
- Chooser uses the real authenticated account playlist loader with pagination, loading/error states and Refresh. Selection is account-revision-bound, so changing accounts or signing out cannot open a previous account's shortcut. No new playlist or Google mutation is created by pinning.
- Make Home structurally less cluttered: combine greeting/search into one compact accent panel, remove duplicated collection tiles and the nine-chip strip, place real playlist covers directly below, and use the first genuine non-Short recommendation as a full-width spotlight before the remaining shelves. Preserve Google order, Shorts format and paused-history notices. Shorts remains accessible in Home alongside Offline and Subscriptions.
- Working native Liked Music, its filters, sleep timer, glass/performance options and TV remote behavior remain unchanged. The playlist shortcut can also be configured from TV Settings.

Hosted validation passed: push 44298530849 and PR 44298541436, including compilation, unit tests, signing verification and publication. New policy regressions cover unassigned/assigned shortcuts, persistence, account revision/sign-out isolation and untrusted IDs; existing music, filter, TV remote and layout tests passed.

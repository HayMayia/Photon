# Photon

An independent, open-source Android client for YouTube videos and music, built on Prism. Choose Photon/Prism or native YouTube-style presentation, with video playback, subtitles, playlists, supported account actions, offline downloads and casting where available.

**Photon is unofficial and is not affiliated with Google or YouTube.** It is an early-stage app; service changes and Google restrictions can interrupt features. Account Home uses an unofficial integration; optional official comment authorization is separate. There is no guarantee that every Google account can sign in.
